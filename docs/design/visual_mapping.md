## 2. 3 级 LOD 与镜头可读性规范（"看得懂"）

1. **`LOD 0`（近景跟随镜头，相机距离 `<= 260m`）**：
   - 显示 3D 胶囊体角色、朝向棱锥 (`FacingPointer`)、地面小光环、主动技能 3D 脉冲光圈 (`SkillAuraRing`)。
   - 头顶 `Label3D` 完整展示两行战术信息：
     - 第一行：`战队简称·选手ID [角色★]`（例如 `FFG·Kronos [IGL★]`）
     - 第二行：`HP:88% A3 G:4 [FIRE]`（实时血量、护甲等级、凝胶护盾库存、当前微操行为标签）
   - 建筑物屋顶自动半透明淡出（Alpha 随相机拉近降至 `0.18`），确保房区攻防一目了然。
2. **`LOD 1`（中景战术镜头，相机距离 `260m ~ 580m`）**：
   - 隐藏朝向小棱锥与技能细节文字，保留 3D 角色主体、放大版地面战术圆盘与精简版头顶标签（`战队·选手 HP%`）。
3. **`LOD 2`（全局俯瞰镜头，相机距离 `> 580m`）**：
   - 隐藏细碎模型与头顶多行文字，切换为高对比度大尺寸 3D 战术棋子 (`MacroBeacon`)，配合 12 支战队专属高饱和色板与低饱和度地形（`S <= 0.35, V <= 0.55`），保证 3 秒内看清全图 12 支队伍的圈位分布与交火热点。

## 3. 主动技能与教练指令的即时反馈（"有手感"）

- **5 大技能类别 (`SkillCategory`) 3D 光环配色**：
  - `HealAura`（治疗光环，如 Alok / Dimitri）：翡翠绿 `#2ED573` 脉冲环
  - `SpeedBurst`（机动爆发，如 Tatsuya / Kelly）：电光青 `#00D4FF` 脉冲环
  - `Shield`（护盾力场，如 Chrono / Xayne）：紫金 `#9E59EB` 护盾环
  - `Scan`（侦察扫描，如 Clu / Homer）：琥珀金 `#FFB800` 扫描环
  - `ArmorBreak`（破甲重击，如 Skyler / Iris）：绯红 `#FF4757` 脉冲环
- **教练临场指令 (`CommandPanel`) 反馈链**：
  - 点击底部 6 大战术指令按钮后，立即进入 `CMD-01` 指挥传达倒计时，随后在 HUD 顶部与右侧事件流弹出 IGL 执行结果（`COMPLIED` 绿色确认 或 `OVERRIDDEN BY IGL` 琥珀色提示），并在 3D 战场上直观看到队伍集火、转移、死守或全员开启主动技能。
